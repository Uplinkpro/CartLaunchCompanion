# Cart Launch Companion 2.0 Theme Guide

## Visual objective

The interface should feel like a premium console-inspired launcher while remaining unmistakably Cart Launch Companion.

## Base palette

- Background: near-black, not gray
- Primary text: white or chrome
- Secondary text: muted silver
- Cart Launch Companion accent: dark purple
- Launcher accent: determined by the selected game's launch provider

## Launcher identity

Launcher identity may affect:

- Overhead light color
- Selected-card accent
- Launcher glyph glow
- Metadata label accents
- Launch-action accent

Launcher identity does not replace Cart Launch Companion branding.

## Lighting

The signature environment uses layered light, not a single glow.

```text
Near-black background
Wide faint beam
Narrow brighter beam core
Subtle haze and dust
Focused light pool
Separate floor plane and reflection
Vignette
```

### Animation

Environmental animation should remain subtle:

- Slow beam drift
- Small opacity breathing
- Minimal haze movement
- Sparse dust
- Smooth launcher-color cross-fade
- No constant distracting motion

### Reduced motion

When reduced motion is enabled:

- Beams remain visible.
- Haze and dust stop.
- Theme changes use short fades.
- Page transitions become simpler.
- Navigation remains immediate.

## Floor

The floor is a separate visual layer, not a color painted into the background.

It should include:

- A subtle horizon
- A dark material texture
- Restrained reflection
- Launcher-colored light response near the selected game

## Chrome

Chrome may be used for:

- Cart Launch Companion cartridge logo
- Launcher glyphs
- Major headings
- Controller prompt glyphs

Chrome should not reduce readability or become reflective noise.

## Page consistency

Home, Metadata, Exit, and Error views use the same:

- Background environment
- Typography
- Prompt controls
- Accent logic
- Focus states
- Transition timing

Exit confirmation is a full application state, not a generic operating-system popup.
