# Cart Launch Companion 2.0 Vision

## Purpose

Cart Launch Companion 2.0 is a premium, portable, cross-platform game launcher for Windows and Linux, including SteamOS.

It remains a launcher, but every interaction should feel as deliberate, consistent, and polished as a first-party console experience.

## Core experience

> **Browse → Confirm → Launch**

1. The user sees a small, curated library.
2. The user selects a game.
3. The user presses **A** to open that game's metadata page.
4. The user reviews the game presentation.
5. The user presses **A** again to launch.
6. Cart Launch Companion hides while the game runs and returns afterward when configured.

## Product boundaries

Cart Launch Companion is:

- A launcher for a small, intentional game library.
- Designed for fullscreen and couch use.
- Controller-first while remaining mouse- and keyboard-friendly.
- Portable across compatible Windows and Linux systems.
- Launcher-agnostic at the presentation layer.
- Focused on clarity, speed, and presentation.

Cart Launch Companion is not:

- A replacement desktop shell.
- A full storefront client.
- A massive library manager.
- A search, filtering, or collection-management application.
- A console operating system.
- A launcher that exposes platform complexity to the player.

## Intended library size

The interface is designed for approximately ten games or fewer.

A small library is a product decision, not a temporary limitation. Every game should feel selected and important.

## Identity

The project should feel like:

> **A launcher with a console-inspired experience.**

The underlying storefront or launch technology is an implementation detail. The player should experience one coherent Cart Launch Companion interface.
