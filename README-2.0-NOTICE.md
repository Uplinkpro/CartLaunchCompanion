> [!IMPORTANT]
> **Cart Launch Companion 2.0 is under active development on the `avalonia-migration` branch.**
>
> Version 2.0 is a from-the-ground-up Avalonia rewrite targeting portable Windows and Linux/SteamOS builds. The stable Version 1 Windows source and release remain available from `main` and the Releases page.
>
> Version 2.0 follows the core flow **Browse → Confirm → Launch** and is designed for a small, curated game library with controller-first navigation.
>
> Development documentation is available in [`docs/2.0`](docs/2.0/).
